# This is an advanced application

I've added some extra code, since this was initially developed for in-house use.  The main function from this packages is `generate_all_data_summaries` and that is what most people will want to use.  If you go to the end of `survey_medley_example.py` you'll see the main part of the code.  The extra code was written to pull VIF estimates from html reports that we generate for some of our  `nilearn`-based analyses.  This is not likely useful to most people but I left it in for those who might be interested in how to pull information from an html file.
